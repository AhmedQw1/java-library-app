# 📚 Java Library App

A simple, desktop-based library management system. I built this as my final project for my Object-Oriented Programming (OOP) course. 

It's not meant to run NASA, but it’s a clean little app that puts core Java and OOP concepts into actual practice! 

##  What it does
* **OOP in Action:** Uses Inheritance and Polymorphism (`Book` and `EBook` classes implementing a `LibraryItem` interface).
* **Smart UI:** A simple dashboard built with Java Swing.
* **Core Features:** Add, edit, remove, and search for books/eBooks.
* **Borrow & Return:** Click a button to check out a book, and the table automatically color-codes the status (Green = Available, Red = Borrowed).
* **Live Stats:** Tracks total, available, and borrowed books in real-time.

##  Built With
* **Java** (Logic & OOP)
* **Java Swing** (Graphical User Interface)
* **ArrayLists** (In-memory data storage)

##  How to Run
1. Clone the repo to your machine.
2. Open the project in NetBeans (or your favorite Java IDE).
3. Run the `LibraryGUI.java` file.
4. Add some books and test it out!
